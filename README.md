# CpuTray 0.13.0

Загрузка CPU, памяти, дисков и сети в трее. Чистый WinAPI, без сторонних библиотек.

## Модули (`src/`)

| Файл | Назначение |
|---|---|
| `appinfo.h` | Имя, версия, описание (`APP_NAME`, `APP_VERSION`, `APP_DESC`) |
| `common.h` | Общие константы (`TOPN`, `MAXD`, `NAME_LEN`, ID иконок) и состояние приложения (`hMain`, `hPop`, `popMode`, тики) |
| `main.cpp` | `wWinMain`, скрытое окно верхнего уровня (получает `TaskbarCreated`), меню, один экземпляр + передача управления экземпляру с правами |
| `app.cpp/.h` | Конвейер такта: опрос (CPU → память → диски → сеть → ETW → процессы) → производные (липкие списки, история) → вывод (иконки, окно) |
| `theme.h` | Палитра |
| `nocrt.cpp` | Сборка без CRT (MSVC): точка входа `WinMainEntry`, `memset`/`memcpy`/`memcmp` |
| `cpu.cpp/.h` | Загрузка по ядрам (`NtQuerySystemInformation`) |
| `mem.cpp/.h` | Память: занято/доступно, кэш, commit (`GlobalMemoryStatusEx`, `K32GetPerformanceInfo`) |
| `history.cpp/.h` | История за 5 минут (300 отсчётов): CPU среднее/пик ядра и память (BYTE), сеть приём/отправка (байт/с) — для графиков |
| `disk.cpp/.h` | Физические диски: активность, чтение/запись, очередь, буквы томов |
| `net.cpp/.h` | Сетевые адаптеры (`GetIfTable2`), масштаб по пику за минуту |
| `procs.cpp/.h` | Снимок процессов каждую секунду (буферы по числу процессов, хэш PID): топ-10 по CPU, вводу-выводу и частной памяти, имена по PID |
| `sticky.cpp/.h` | «Липкие» топ-списки CPU/памяти/ввода-вывода (10) и по дискам (по 4): обновляются каждую секунду, окно открывается сразу с данными; выбывший процесс ещё 5 с виден серой строкой со своим пиком, общая сортировка по значению |
| `autostart.cpp/.h` | Проверка прав администратора, перезапуск с повышением, автозапуск через реестр `HKCU\...\Run` (значение `CpuTray`, без прав администратора) |
| `etw.cpp/.h` | Трассировка ядра (ETW): работает постоянно с запуска (сессия `CpuTray`; повтор раз в 15 с при ошибке, проверка сессии и потерь событий раз в 10 с; кэш поток→процесс 30 с): процессы по дискам, сетевой трафик процессов с запуска (хэш-таблицы по PID; список сети — топ-10 по принятому с запуска, текущие скорости, процессы без трафика 5 с или завершённые — серым, имя запоминается) (нужны права администратора) |
| `format.cpp/.h` | `FmtRate` (Б/с…МБ/с), `FmtBytes` (КБ…ТБ), `FmtSize` (тома, целые ГБ) |
| `trayicon.cpp/.h` | Рисование иконок-столбиков и `Shell_NotifyIcon` (VERSION_4); иконки добавляются заново, если трей их потерял |
| `popup.cpp/.h` | Окно-подсказка: позиционирование у иконки с учётом DPI монитора, перерисовка |
| `draw.cpp/.h` | Примитивы отрисовки: строки, полосы, график, общая строка процесса `ListRow`, шрифт под DPI |
| `views.cpp/.h` | Содержимое окна по режимам: CPU, память, диски, сеть; размеры и цвета |

## Сборка

Нужны VS 2022 Build Tools (C++). Запустить `build.bat`: собирает все `src\*.cpp`, кладёт `cputray.exe` в корень проекта и удаляет `.obj`. Сборка без CRT (`/NODEFAULTLIB`, своя точка входа): exe ~30–40 КБ.
Другой путь к студии можно задать переменной `VSINSTALL`.

## Меню

«Запускать с Windows» (галочка; значение `CpuTray` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`), «Перезапустить от администратора» (только без прав), «О программе», «Выход».
Запущенный с правами экземпляр сам закрывает уже работающий экземпляр без прав.
Автозапуск идёт без прав администратора, поэтому трассировка (процессы по дискам и сети) не работает: для неё нужен «Перезапустить от администратора».
Если от версии 0.11.0 осталась задача Планировщика `CpuTray`, удалите её вручную: `schtasks /Delete /TN CpuTray /F` (от администратора).

## Замечание

Античиты (например, Easy Anti-Cheat в Apex Legends) блокируют трассировку ядра (ошибка 5). Пока игра запущена, списки процессов по дискам и сети скрыты; трассировка перезапускается сама в течение ~15 с после выхода из игры.
